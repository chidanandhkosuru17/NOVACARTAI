# NOVA CART – AI-Powered Local Commerce & Business Rescue Ecosystem

**NOVA CART** is an executive-grade, connected quick-commerce ecosystem and business turnaround platform operating across **620 local stores** in **Bengaluru, Mumbai, Delhi NCR, and Hyderabad**.

### Connected Ecosystem Architecture:
1. **🛍️ NOVA CART Customer Shopping Application**: Local store discovery in Hyderabad (Madhapur, Kukatpally, Gachibowli, Kondapur, Miyapur), categories, out-of-stock product substitution engine, transparent pricing with zero surprise charges, 6-stage order tracking, and 3-streak loyalty points.
2. **🏪 NOVA CART Retailer Management Portal**: Merchant order fulfillment (Accept, Reject with reason, Prepare, Ready, Handover), live inventory synchronization, stock status monitoring, and "Busy Store Mode" toggle (+20m prep time).
3. **🏛️ NOVA CART Admin Command Center**: 9 baseline KPIs diagnostics, 7 customer retention cohorts, smart inventory problem detection, real-time order rescue desk, explainable AI recommendations, marketing studio (₹17L burn, ₹25L cap), rapid refund support center, and ₹25L 6-month scenario simulator.
4. **💾 Firebase Firestore Database & Authentication**: Shared persistent database (`ai-studio-0a20f08e-bdac-447f-9503-70bbdee36e89`) and Google Auth + instant Demo Persona switcher.
5. **🎯 10-Step Interactive Startup Competition Tour**: Guided walkthrough of customer shopping, grocery checkout, retailer order acceptance, inventory mismatch guard, alternative store substitution, and admin turnaround simulation.

## 2. Core Modules Architecture

1. **Module A: Executive Dashboard**
   - KPI comparison cards with historical 6-month deltas.
   - Interactive trend charts (Revenue vs Burn, Repeat Rate vs Cancellations, Delivery vs Tickets).
   - Business Health Matrix highlighting management red flags and evidence-based hypotheses.
   - **Executive CSV Export**: One-click download of all current performance metrics across Financials, Retention, Operations, Marketing, and Support, plus historical 6-month time-series trends for offline analysis.

2. **Module B: Customer Intelligence & 3-Order Milestone**
   - 7 RFM behavioral cohorts (New, Active, Repeat Champions, At-Risk, Inactive, Discount-Dependent, Multi-Category).
   - Tailored retention nudges and direct 1-click campaign generation.
   - Proof that reaching Order #3 increases repeat probability to 72%.

3. **Module C: Smart Inventory Management**
   - Live catalog sync for 620 Kiranas, Pharmacies, Bakeries, and Stationery shops.
   - Stock accuracy scoring (74% baseline → 95% target).
   - Instant stock adjustment, auto-masking zero-stock items, and WhatsApp 1-tap verification.

4. **Module D: Order Rescue & Delivery Operations**
   - Live order stream monitoring SLA delays.
   - Transparent risk heuristic engine (store unacknowledged >4m, rider search >6m, delivery projection >35m).
   - 1-tap intervention actions: Store audio alert, priority dispatch bounty, proactive ₹50 delay credit.

5. **Module E: Smart Promotions & ROI Simulator**
   - Campaign portfolio management.
   - Interactive budget reallocation slider (simulating transition from 58% acquisition burn to 68% retention focus).
   - Projection of coupon redemption, CAC, and marketing ROAS.

6. **Module F: Customer Support & Instant Refunds**
   - Centralized ticket dispute desk with categorization (Refund, Delay, Missing Product, Coupon).
   - Instant UPI webhook simulation for merchant-rejected orders.
   - Root-cause diagnostics to reduce resolution times from 9.2 hours to sub-2 hours.

7. **Module G: Central Business Rescue Simulator**
   - Multi-variable 6-month projection engine.
   - Adjustable levers: Repeat Rate, Cancellation Rate, Delivery Time, Inventory Accuracy, AOV.
   - Side-by-side comparison with baseline, net turnaround ROI computation, and confetti celebration.
   - Cloud Firestore scenario persistence.

8. **Module H & Budget: 6-Month Action Plan & ₹25 Lakh Planner**
   - Visual month-by-month roadmap with interactive task completion checkboxes.
   - Capital allocation planner enforcing the mandatory ₹25.0 Lakh budget ceiling with over-budget alerts.

9. **Module 9: AI-Style Recommendation Hub**
   - Explainable rule-based recommendation cards with priority flags and strategic rationale.

10. **Module 10: Store Maps Radar (Google Maps Grounding)**
    - Uses `gemini-3.5-flash` with the `googleMaps` tool to verify retailer geo-density, local store coordinates, and delivery cluster feasibility across Bengaluru, Mumbai, and Delhi NCR.
    - Extracts live Google Maps links and review citations directly from `groundingMetadata.groundingChunks`.

11. **Module 11: Market Trends Radar (Google Search Grounding)**
    - Uses `gemini-3.5-flash` with the `googleSearch` tool for live quick-commerce competitive intelligence.
    - Monitors competitor delivery SLAs (Zepto, Blinkit, Instamart), FMCG margin movements, and consumer retention dynamics with cited web sources.

12. **Module 12: Promo Video Studio (Veo Video Generation)**
    - Powered by `veo-3.1-fast-generate-preview`.
    - Allows merchants and marketers to upload photos or select sample quick-commerce products and render cinematic promotional videos.
    - Supports both **16:9 Landscape** (Web & Desktop Banners) and **9:16 Portrait** (Instagram Reels, Stories, TikTok Ads) with in-app streaming and download.

13. **Competition Tour & Executive Impact Audit**
    - 9-step guided walkthrough for evaluators and judges.
    - One-click CSV export and executive summary clipboard copy.

14. **Top Navbar KPI Safety Threshold Alerts System**
    - Automated real-time telemetry monitoring critical quick-commerce metrics against configurable safety ceilings:
      * **Cancellation Rate Breach**: Alerts when cancellations exceed the pre-defined ceiling (e.g. 11.0% vs 7.0% safe threshold).
      * **Support Ticket Surge**: Alerts when monthly tickets exceed desk capacity (e.g. 5,900 vs 4,000 threshold).
      * **Delivery SLA Latency**: Alerts when delivery times exceed quick-commerce guarantees (e.g. 37m vs 30m target).
      * **Customer Repeat Rate Floor**: Warns when repeat rate drops below the retention baseline (e.g. 27% vs 35% floor).
      * **Coupon Breakage Waste**: Warns when marketing coupon breakage exceeds capital limits (e.g. 44% vs 30%).
    - Dynamic popover with direct one-click intervention buttons ("Launch Order Rescue", "Open Support Desk", etc.).
    - In-app threshold configuration sliders allowing executives to test custom tolerance ceilings in real time.

## 3. Technology Stack & Integrations

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Recharts, Canvas Confetti.
- **Backend & Persistence:** Firebase Auth (Google Sign-In with Demo user fallback), Cloud Firestore Enterprise (`ai-studio-0a20f08e-bdac-447f-9503-70bbdee36e89`), LocalStorage fallback.
- **Security:** Strict Attribute-Based Access Control in `firestore.rules` preventing identity spoofing and payload exhaustion.

## 4. Mobile Web Application & PWA Features

NOVA CART is fully engineered as an installable Mobile Web App (PWA):
- **Native-Style Bottom Navigation Bar**: Quick touch navigation across Executive, Retention, Inventory, Order Rescue, and Simulator, plus a comprehensive slide-over drawer for secondary tools.
- **PWA Installability**: Includes Web App Manifest (`manifest.json`), high-resolution SVG and maskable brand icons, and one-tap install prompts on Android/Chromium with guided instructions for iOS Safari.
- **Touch Ergonomics**: All interactive elements (stock adjusters, rescue buttons, sliders, filter pills) provide minimum 44px touch targets.
- **Safe-Area Inset Support**: Designed for edge-to-edge displays on iPhone and Android notches (`viewport-fit=cover`).

## 5. Getting Started

1. Clone or launch the AI Studio workspace.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server on port 3000:
   ```bash
   npm run dev
   ```
4. Click **"Competition Tour"** in the top navigation bar to take the guided 9-step evaluation tour, or tap **"Install App"** to install on mobile!
